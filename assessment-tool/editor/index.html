Downloaded scenarios.js — now publish it

  1. Open the assessment-tool folder upload page on GitHub.
  2. Drag the scenarios.js file you just downloaded onto that page. (If your browser renamed it, e.g. "scenarios (1).js", rename it back to scenarios.js first.)
  3. Type a short note about what you changed, then click Commit changes.
  4. Within a minute or two the assessment tool updates for everyone. Refresh this editor afterwards; it will show "No changes".
